# Computer Architecture Lab Project  
**Jan 2025 – April 2025**  

**Tech Stack:** Java, ToyRISC ISA  

## Description

- Built an assembler that converts `.asm` files to `.out` files.  
- Simulated a single-cycle processor, which was later extended into a 5-stage pipelined processor with hazard resolution using interlocks.  
- Implemented a discrete event simulator to model latency and instruction execution time.  
- Integrated caches to reduce memory latency and improve performance.
